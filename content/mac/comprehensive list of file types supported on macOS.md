## 📄 Documents

- **.pdf** - PDF documents
- **.doc, .docx** - Microsoft Word[^19_10]
- **.pages** - Apple Pages
- **.txt** - Plain text
- **.rtf** - Rich Text Format[^19_10]
- **.odt** - OpenDocument Text


## 📊 Spreadsheets \& Data

- **.xls, .xlsx** - Microsoft Excel[^19_10]
- **.numbers** - Apple Numbers
- **.csv** - Comma-separated values
- **.ods** - OpenDocument Spreadsheet


## 📽️ Presentations

- **.ppt, .pptx** - Microsoft PowerPoint[^19_10]
- **.key** - Apple Keynote


## 🖼️ Images

- **.jpg, .jpeg** - JPEG images[^19_5][^19_10]
- **.png** - Portable Network Graphics[^19_5]
- **.gif** - Graphics Interchange Format (including animated)[^19_5]
- **.heic, .heif** - High Efficiency Image Format[^19_5]
- **.tiff, .tif** - Tagged Image File Format[^19_5]
- **.bmp** - Bitmap[^19_5]
- **.psd** - Adobe Photoshop (merged and layered)[^19_5]
- **.raw** - RAW camera formats[^19_5]
- **.svg** - Scalable Vector Graphics
- **.tga** - Targa[^19_5]
- **.sgi** - Silicon Graphics Image[^19_5]
- **.webp** - WebP images
- **.icns** - Mac icon files
- **.ico** - Windows icon files


## 🎥 Video

- **.mp4** - MPEG-4 video[^19_5]
- **.mov** - QuickTime Movie[^19_5]
- **.m4v** - MPEG-4 Video
- **.avi** - Audio Video Interleave
- **.mkv** - Matroska Video
- **.hevc** - High Efficiency Video Coding[^19_5]
- **.dv** - Digital Video (DVCAM, DVCPRO)[^19_5]
- **.mpeg, .mpg** - MPEG video
- **.wmv** - Windows Media Video
- **.flv** - Flash Video
- **.webm** - WebM video
- **.3gp** - 3GPP video


## 🎵 Audio

- **.mp3** - MP3 audio[^19_5]
- **.m4a** - MPEG-4 Audio
- **.aac** - Advanced Audio Coding[^19_5]
- **.wav** - Waveform Audio[^19_5]
- **.aiff, .aif** - Audio Interchange File Format[^19_5]
- **.caf** - Core Audio Format[^19_5]
- **.flac** - Free Lossless Audio Codec
- **.ogg** - Ogg Vorbis
- **.wma** - Windows Media Audio
- **.alac** - Apple Lossless


## 💻 Code \& Development

- **.swift** - Swift code
- **.js** - JavaScript
- **.py** - Python
- **.html** - HTML[^19_10]
- **.css** - Cascading Style Sheets
- **.json** - JSON data
- **.xml** - XML data
- **.yaml, .yml** - YAML data
- **.sh** - Shell script
- **.c, .cpp, .h** - C/C++ code
- **.java** - Java code
- **.rb** - Ruby
- **.php** - PHP
- **.sql** - SQL databases


## 📦 Archives \& Compression

- **.zip** - ZIP archive
- **.dmg** - Disk Image
- **.pkg** - Package installer
- **.tar** - Tape archive
- **.gz, .gzip** - Gzip compressed
- **.bz2** - Bzip2 compressed
- **.rar** - RAR archive
- **.7z** - 7-Zip archive
- **.sit, .sitx** - StuffIt archive


## 🗂️ Disk \& File System Formats

- **APFS** - Apple File System (default for macOS 10.13+)[^19_4][^19_11]
- **HFS+** - Mac OS Extended (Journaled)[^19_3][^19_4]
- **exFAT** - Compatible with Windows and Mac[^19_3][^19_4]
- **FAT32** - MS-DOS (FAT)[^19_4]
- **NTFS** - Windows (read-only on Mac)[^19_3]


## 🌐 Web \& Email

- **.html, .htm** - Web pages
- **.mht, .mhtml** - Web archive
- **.webarchive** - Safari web archive
- **.eml** - Email message
- **.vcf** - vCard contact
- **.ics** - iCalendar


## 📚 eBooks

- **.epub** - EPUB eBook
- **.mobi** - Kindle format
- **.ibooks** - Apple Books


## 🎨 Design \& 3D

- **.ai** - Adobe Illustrator
- **.sketch** - Sketch design
- **.fig** - Figma (web-based)
- **.indd** - Adobe InDesign
- **.obj** - 3D object
- **.fbx** - 3D model
- **.stl** - 3D printing


## 🔐 System \& Application

- **.app** - macOS application bundle
- **.dmg** - Disk image
- **.pkg** - Installer package
- **.dylib** - Dynamic library
- **.framework** - Framework bundle
- **.plist** - Property list
- **.scpt** - AppleScript
- **.command** - Terminal command


## 🔑 Security \& Encryption

- **.cer, .crt** - Certificate
- **.pem** - Privacy Enhanced Mail
- **.p12, .pfx** - Certificate archive
- **.key** - Private key

This covers the vast majority of file types you'll encounter on a Mac! The exact support depends on what applications you have installed, but macOS natively handles most common formats.[^19_4][^19_5]

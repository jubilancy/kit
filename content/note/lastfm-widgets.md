# Last.fm API Widgets Kit

Last.fm's official widgets are gone, but the API still powers a thriving ecosystem of third-party tools. Here's where to find widgets for your website, streams, and home screen.

---

## Web & Blog Widgets

Embed your listening history or "now playing" status on personal sites and profiles.

| Tool | Best For | What You Get |
|------|----------|--------------|
| [lastfm-widgets](https://github.com/StigNygaard/lastfm-widgets) | Recent scrobbles | Modern web component with retro feel and album headers |
| [last.played](https://www.reddit.com/r/lastfm/comments/1ig1wck/announcing_lastplayed_a_widget_maker_to_show_off/) | Forum signatures | Image link showing your latest track and user details |
| [LastFM-widget-netlify-functions](https://andrewford.co.nz/articles/lastfm-widget-netlify-functions/) | Developers | Serverless widget builder using Netlify and the API |
| [DAKboard Widget](https://www.reddit.com/r/dakboard/comments/11ri22t/made_a_widget_to_display_lastfm_now_scrobbling/) | Smart displays | Now playing with artist and album art |

---

## Streaming & OBS Overlays

Show your current track to Twitch viewers or stream audiences.

| Tool | Platform | Setup |
|------|----------|-------|
| [Fast & Simple Music Widget](https://obsproject.com/forum/resources/fast-simple-music-widget.2202/) | OBS | Lightweight browser source; auto-themes from album art |
| [StreamElements Music Widget](https://fourthwall.com/features/apps-and-integrations/stream-alerts) | StreamElements | Direct Last.fm integration into overlay setups |
| [DeepBot Now Playing](https://wiki.deepbot.tv/now_playing_song_widget_last_fm) | DeepBot + OBS | Specialized widget for DeepBot users |

## Developer Resources

Build your own custom widget.

**Start here:**
- [Last.fm API Account](https://www.last.fm/api/downloads) — Free key required for all tools

**Templates & Examples:**
- [lastfm-recent-tracks (Glanceapp)](https://github.com/glanceapp/community-widgets/blob/main/widgets/lastfm-recent-tracks/README.md) — Community widget template
- [lastfm-friends-who-listen](https://github.com/xxdavid/lastfm-friends-who-listen) — Browser extension to restore "friends who listen" feature

---

## How to Get Started

1. **Get an API key** from [Last.fm API](https://www.last.fm/api/downloads)
2. **Pick your use case** — web widget, stream overlay, or mobile widget
3. **Deploy** — Most tools are plug-and-play; developers can customize with API access

The Last.fm ecosystem is alive in third-party tools. Find one that fits your workflow.
